VL Effects portable mode

While this file sits next to effectcraft.exe, VL Effects keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the EffectCraftData folder beside it instead of
%APPDATA%\VL Effects. Copy the whole folder to move VL Effects with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\VL Effects unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\VL Effects) instead.
If EffectCraftData can't be written (for example on a read-only drive), VL Effects logs a
warning and uses %APPDATA%\VL Effects instead.
